# AutoTessell 자율 개선 로드맵

이 문서는 매 라운드의 출발점이다. 구현 순서는 추측이 아니라 계획서,
evidence matrix, 실제 코드, 재현 가능한 측정으로 결정한다. 한 카드는 한
메커니즘만 다루며, 기본값은 보수적으로 유지한다.

## 최상위 종료 조건

1. 입력 표면의 정점·면 집합·면적·patch/provenance가 허용된 표면 카드 외에는
   변하지 않는다.
2. manifold/watertight, 양의 체적, 무퇴화, face owner/neighbour pairing,
   star-validity와 결정론 gate가 모두 통과한다.
3. 품질 개선은 기존 permanent gate를 완화하지 않고, 전 형상 회귀와 canonical
   bench를 통과한다.
4. 무효 후보는 삭제·부분 적용하지 않고 전체 transaction을 되돌린다.
5. 효과가 없거나 조건부인 카드는 `measured, falsified` 또는 `default OFF`로
   기록한다. 문헌의 아이디어를 이름만 보고 포팅하지 않는다.

## native_tet 남은 작업

### 유지해야 할 것

- naca0012의 collapse/flip/stellar/metric-GAP boundary guard와
  `boundary_invariant` 하니스를 permanent regression으로 유지한다.
- dual_torus CVT lock 수정은 유지하되, BSP/CDT 후보는 기본 OFF다.
- `TET-SHAPE-2` GSM pass는 default OFF 상태에서만 유지한다.

### 실행 순서

1. `TET-BSP-RECOVERY-CORRECTNESS-1`의 fixed-condition 측정은 종료한다.
   OFF를 기본으로 유지하고, fixed-condition coarse/fine과 current
   `_phase_bc_skip` route를 섞지 않는다.
   재실행하고, edge/face recovery 전후의 boundary key, area, negative/degenerate
   tet, deterministic digest를 비교한다.
2. `_tet_boundary_faces` caller import fix를 유지한다. FLOW-3는 naive
   전역 재계산 비용과 worst-Q 불변으로 보류한다. 다음은 cavity-local
   evaluator와 TET-WDEL-3 clearance 진단 중 하나를 단독 측정한다.
   TET-LAZY-1/SHAPE-3(a)는 60/61 private-copy 개선만 확인됐고 최악 품질은
   변하지 않았으므로 기본 OFF다. TET-LAZY-2는 bounded 표본 0승인,
   TET-WDEL-2는 8.2% 일치로 기록하고 승격하지 않는다.
3. 61개 wedge는 구조적 xfail로 남기되, FSL 카드가 실제로 제거 가능한 wedge와
   unflippable wedge를 분리한다는 진단 결과를 보존한다.
4. correctness gate가 닫히기 전에는 병렬화 카드를 착수하지 않는다.

## native_hex 남은 작업

1. wall-fit correctness guard는 유지한다. `HEX-WALLFIT-PARETO-1`은
   cylinder/sphere area error `17.214→0.275%`, `41.070→0.037%`와 동시에
   skew `0.699→9.486`, `0.930→8.779`가 악화됨을 확인했다. gear/bracket도
   전역 승격 기준을 만족하지 못했으므로, 다음은 문헌 기반 local
   surface-constrained Pareto 후보 진단이다.
2. `HEX-TRANS-2` 결과는 cylinder/gear의 transition enrichment와 sphere의
   포화 상태를 분리해 기록한다. 전이 전용 품질 solver나 전역 threshold는 아직
   만들지 않는다.
3. provenance retention이 닫힌 뒤에만 wall-fit 후보별 `Δskew`, `Δwarpage`,
   `Δarea`, `Δwall_dev`, signed-volume을 cylinder/sphere/gear/bracket에서
   교차 분석하고, 특정 provenance class의 국소 transaction만 검토한다.
4. transition element 품질 복구 문헌과 feature/curve/corner provenance 문헌의
   FULL_READ 근거를 유지한다. surface movement policy는 승인 전까지 바꾸지
   않는다.
5. `HEX-OCT-SCALE-QUALITY-1`의 permanent skew `3.0`은 완화하지 않는다.

## native_poly 남은 작업

### 이미 반증된 경로

- 단순 simplex facetization: boundary face 폭증으로 기각.
- source-cap 재구성: 일부 cap만 좋아지고 internal invalidity가 남아 기각.
- 기존 ring completeness/order 수정: ring 누락·self-intersection이 없어 주원인 아님.
- 기존 정점/새 중심 fan triangulation: topology/invalidity가 악화되어 기각.
- raw circumcenter: fixed native에서 cube/cylinder/sphere candidate invalid가
  centroid보다 나빠져 기각.
- interior-only 단순 local move: well-centered 비율과 penalty는 일부 개선됐지만
  centroid-dual invalidity가 변하지 않아 충분한 repair가 아님.
- hybrid point: well-centered tet만 circumcenter를 사용해 sphere candidate를
  줄였지만 cube/cylinder invalid가 남아 whole-candidate guard가 기각.

### 다음 실험

1. `POLY-DUAL-TOPOLOGY-1` false alarm을 기록하고 종료한다. 수정된 topology
   census는 cube/cylinder/sphere에서 incomplete internal link `0/0/0`이며,
   native-tet audit와 일치한다.
2. 그 결과에 따라 weighted/well-centered objective 또는 dual face
   warpage·pairing을 직접 포함한 opt-in 후보를 하나만 만든다.
3. 모든 후보는 boundary vertices 고정, tet connectivity 고정, orientation·volume
   보존, dual face pairing, star-validity, deterministic replay를 함께 검사한다.
4. cube/cylinder의 negative internal FV coefficient가 해소되지 않으면 solver
   correction을 생산 경로에 올리지 않고 FV prerequisite를 계속 BLOCKED로 둔다.
5. 유효성 문제가 닫힌 뒤에만 Phase 2 repair(`POLY-CONCAVE-SPLIT1`/
   `POLY-DUAL-UNTANGLE1`)를 재개한다. 현재 fan fixture가 재현되지 않으면 dormant로
   유지한다.

Well-centeredness 후보는 [Well-Centered Triangulation](https://arxiv.org/abs/0802.2108),
[Triangulation of Simple 3D Shapes with Well-Centered Tetrahedra](https://arxiv.org/abs/0806.2332),
그리고 [Quality Meshing with Weighted Delaunay Refinement](https://epubs.siam.org/doi/10.1137/S0097539703418808)을
근거 큐로 사용한다. 이 문헌들은 boundary를 고정한 내부 최적화 또는 weighted
Delaunay 생성의 방향을 지지하지만 현재 dual face gate를 면제하지 않는다.

## native_tri 남은 작업

1. metric field를 cube/sphere/cylinder/feature fixture에 대해 repeat run하고,
   split/collapse/flip/smooth 이후 SPD remap, feature lock, tangent normal
   discontinuity rejection을 기록한다.
2. `TRI-SIZING-METRIC-ALG1`: Frey식 metric intersection을 실제 edge target
   판단에 사용하되, 기존 scalar target의 isotropic limit와 bit-identical
   topology gate를 확인한다.
3. `TRI-CURV-SIZE1`/`TRI-ADAPT-LOOP1`: 곡률 source, endpoint-minimum sizing,
   bounded rounds/stagnation stop을 분리 검증한다.
4. 그 뒤 sampled Hausdorff drift gate와 bijective shell gate를 연결한다. shell은
   operator guard의 대체가 아니라 round-level 추가 안전망이다.
5. `TRI-OPERATOR-PERF-1`: high-genus dual-torus operator round의 단계별 시간과
   candidate 수를 계측해 O(n²) 후보 재계산인지, 반복 정체인지 분리한다.
6. 전체 suite가 240초를 넘는 경우는 테스트 실패로 단정하지 말고, native-tri
   핵심 suite와 poly/CLI 통합 smoke를 분리한다.

## 라운드 운영 템플릿

각 라운드는 다음 순서로 끝낸다.

1. dirty worktree와 staging을 먼저 확인한다.
2. 현재 카드의 before 수치를 고정한다.
3. 단일 후보를 opt-in 또는 report-only로 실행한다.
4. invariant → validity → quality → performance → determinism 순으로 검사한다.
5. 결과를 계획서, evidence matrix, CHANGELOG, [[log|위키 작업 기록]]에 남긴다.
6. 다음 라운드의 단일 카드와 중단 조건을 이 문서와 ROADMAP에 갱신한다.

## 2026-07-27 라운드 결과

- native_poly: fixed-native well-centered audit을 재현했고, interior-only local
  move와 centroid/circumcenter hybrid를 측정했다. 추가로 topology-map false
  alarm을 수정했고, face-warpage relocation은 cube/cylinder invalidity를
  개선하지 못했다. 둘 다 production에는 연결하지 않았다. focused poly suite는
  `22 passed`.
- native_tri: metric/operator 핵심 suite는 `33 passed`. 전체 `tests` 실행은
  poly/CLI smoke가 포함된 통합 경로에서 240초 제한을 넘어 별도 분리 대상으로
  남겼다. 실패 assertion은 확인되지 않았다.
- 코드 변경은 poly의 exact Hull 우선/QJ fallback과 진단 스크립트·문서만 현재
  WIP에 남아 있으며, 커밋·staging은 하지 않았다.
- native_hex 문헌 gap search 문서를 보완하고, `HEX-TRANS-2`를 새 fine/pre-BL
  출력에서 재실행했다. bad direct-transition은 cylinder `344/344`, sphere
  `918/960`, gear `68/68`이었고, bad face provenance는 모두
  `smooth/defaultWall`이었다. transition-only solver는 열지 않았다.

## 다음 라운드의 첫 실행

`HEX-PROV-RETENTION-1`과 `HEX-GEAR-DEGEN-DROP-1`은 완료됐다. cylinder/sphere
writer topology는 보존됐고 gear의 `_wall_fit_snap` face-area guard가 세 paired
zero-area key와 six-cell drop을 제거했다. 다음 첫 실행은 native_tet
`TET-FLOW-3` 단독 측정 뒤 native_tet 기본 경로의 반복 결정론을 조사했다.
Delaunay와 P4C OFF native-only는 byte-identical이었지만 P4C ON pytetwild는
`num_threads=1`, 최적화 OFF에서도 매번 달랐다. 첫 `random_device`를 고정한
vendored 재빌드도 충분하지 않았으므로, fTetWild 전체 ordering 정규화 또는
self-native 결정론 lane 비교를 먼저 수행하고 WDEL-3를 재개한다.
어떤 경우에도 raw circumcenter, face deletion, gate 완화, 병렬화 카드는
자동으로 승격하지 않는다.
