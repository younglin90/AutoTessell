# 2026-07-26 문헌 읽기와 다음 개선 카드

## 읽는 원칙

이번 기록은 검색 결과의 제목만 모은 목록이 아니다. 출판사 페이지나 공개 원문에서 확인한 주장만 현재 계획에 반영한다. 초록만 확인한 논문은 구현 근거로 승격하지 않고 `ABSTRACT_ONLY`로 남긴다. 프로젝트의 표면 보존, 결정론, 영(0) 또는 음의 부피 금지 게이트는 문헌보다 우선하는 제품 불변식이다.

## 이번 라운드의 결론

현재 네 엔진에서 다음으로 조사할 문제는 서로 같은 “품질 개선”이 아니다.

| 엔진 | 현재 남은 문제 | 문헌이 지지하는 다음 조사 | 당장 구현하지 않는 이유 |
|---|---|---|---|
| `native_hex` | octree 전이 구간의 scattered bad-face와 patch provenance | 전이 템플릿/transition-chain의 사전 조건과 국소 품질 계측 | ECR와 sheet extraction이 네 형상에서 반증됐으므로 generic untangler를 다시 넣을 근거가 없음 |
| `native_tet` | `TET-SHAPE-2`의 안전한 내부 GSM pass 이후 남은 worst-tail | reversible lazy flip와 내부-only moving-mesh 비교 측정 | 경계 정점을 움직이는 RBF/flow는 현재 계약과 충돌할 수 있음 |
| `native_poly` | non-manifold fan의 2개 invalid dual cell | concave boundary의 conical split 가능성 진단 | centroid 재배치만으로는 같은 2/18이 남았으므로 placement 반복은 중단 |
| `native_quad` | POSY 후보에서 `+1/2` branch가 사라지는 위치 singularity | messy grid-preserving map의 허용 오차·불일치 원장 | extraction을 바꾸기 전에 허용 가능한 map deviation을 수치화해야 함 |

## 원문 또는 공개 원문을 읽은 항목

### 1. 사면체: Dassi et al. 2017 — `FULL_READ`

[Tetrahedral mesh improvement using moving mesh smoothing, lazy searching flips, and RBF surface reconstruction](https://arxiv.org/abs/1703.07007)

저자들은 moving-mesh PDE smoothing, reversible lazy flip, RBF 표면 재구성을 한 루프로 결합한다. 공개 원문에서 다음을 확인했다.

- Laplacian smoothing은 품질 향상과 유효성 보장을 하지 않는다.
- moving-mesh functional의 gradient flow는 초기 유효 mesh를 유효하게 유지한다는 이론을 전제로 한다. 수치 적분도 에너지를 단조 감소시키는 조건이 필요하다.
- 경계 정점은 고정하거나, 허용된 곡선/표면의 접선 방향으로만 움직인다. 일반 곡면에서는 이동 후 projection을 별도 단계로 둔다.
- lazy flip은 한 번의 edge removal을 위해 여러 flip을 탐색하고, 품질이 좋아지지 않으면 전체 시퀀스를 되돌린다. 저자들은 이 전파성 때문에 flip을 smoothing처럼 독립 병렬 연산으로 취급하지 않는다.
- stagnation 뒤에는 edge split, contraction, point insertion을 쓰며, 경계와 내부에 서로 다른 계약을 둔다.

현재 코드에 대한 해석은 명확하다. `TET-SHAPE-2`는 내부 정점만 고정된 경계 집합 아래에서 움직이고 signed-volume transaction을 검사하므로 이 문헌의 안전한 부분과 정합한다. 다음 tet 카드는 “새 global smoother 추가”가 아니라 **내부-only reversible lazy-flip 측정**이어야 한다. boundary projection/RBF는 surface hash 계약을 먼저 만들기 전에는 후보에서 제외한다.

### 2. 사면체: MFRC 2021 — `FULL_READ`

[An efficient method to improve the quality of tetrahedron mesh with MFRC](https://www.nature.com/articles/s41598-021-02187-1)

MFRC는 최악 사면체를 감싸는 cavity를 만든 뒤, 가능한 face–candidate vertex 조합을 탐색해 더 나은 분해를 찾는다. 공개 원문에서 다음을 확인했다.

- cavity 내부의 후보는 방향, 교차, 품질을 모두 검사한다.
- concave cavity도 허용하며, sub-cavity와 tetra quality를 memo에 저장해 반복 계산을 피한다.
- 경계 요소는 원래 표면과 일치해야 하므로 수정하지 않는 것을 명시한다.
- edge removal과 multi-face removal이 실패했을 때만 cavity reconstruction과 내부 정점 조정을 사용한다.
- cavity 크기가 계산 시간을 지배하므로 최대 cavity node 수를 제한해야 한다.

이는 현재 `collapse_short_edges`/`flip_edges_44`/`stellar`에서 발견한 “영향 영역을 전부 검증하지 않고 일부 tet만 삭제”했던 과거 버그와 직접 연결된다. MFRC식 후보 검증은 향후 필요할 수 있지만, 큰 cavity 재구성은 성능 카드 없이 바로 넣지 않는다. 먼저 영향 tet/face 집합, boundary face-set, signed volume을 기록하는 read-only 진단부터 한다.

### 3. Polyhedral mesh: concave-edge treatment 2015 — `ABSTRACT_READ`

[Polyhedral Mesh Generation and A Treatise on Concave Geometrical Edges](https://doi.org/10.1016/j.proeng.2015.10.131)

초록에서 세 가지 방향을 제시한다. concave edge에 non-manifold surface를 삽입해 내부 경계로 다루는 방법, concave polyhedral cell을 conical cell로 분해한 뒤 concave edge를 따라 이분하는 방법, 그리고 boundary-conforming primal mesh를 이용해 dual 경계의 복잡도를 줄이는 방법이다.

현재 non-manifold fan에서 `cell=2, edge=(4,0)` invalid가 centroid와 Garimella 후보 모두에서 그대로 남은 사실과 맞는다. 다음 poly 카드는 점을 다시 옮기는 카드가 아니라, **해당 cell이 conical split으로 분해 가능한지 판정하는 진단 카드**여야 한다. 실제 split은 fixture의 patch/type provenance와 surface vertex 불변식을 함께 검증한 뒤에만 열 수 있다.

### 4. Quad extraction: Ray 2025 — `ABSTRACT_READ`

[On Quad Mesh Extraction From Messy Grid Preserving Maps](https://arxiv.org/abs/2507.15404)

초록의 핵심은 grid-preserving map에서 조금 벗어난 실제 입력을 “대충 추출”하지 말고, 허용 가능한 deviation을 명세하고 그 deviation을 discrete operation sequence로 표현해야 한다는 것이다. 이는 `QUAD-POSY1`이 `+1/2` branch를 되살리지 못한 현재 결과와 직접 연결된다.

다음 quad 카드는 추출 알고리즘 변경이 아니라 map deviation ledger다. 위치 singularity, branch offset, local integer discrepancy를 기록하고, 허용 범위를 먼저 정한다. 논문 전문을 확인하기 전에는 extraction 규칙을 바꾸지 않는다.

### Xu et al. 2017 — edge-angle 최적화

이 논문은 ECR처럼 전체 mesh를 한꺼번에 최적화하는 논문이 아니라, inverted 또는 목표 MSJ 미달 요소 주변의 **2-ring local region**만 복사해 최적화하는 방식이다. 핵심은 다음과 같다.

- 직교성, 같은 parameterization 방향의 straightness, irregular edge의 이상각을 하나의 edge-pair angle energy로 통합한다. 이상각은 내적 목표값으로 표현되므로 cone normal을 따로 추정하지 않는다.
- local region의 경계 정점은 고정한다. surface 정점은 regular/tangent-plane, feature-edge, corner로 분류하고 각각 접선 평면·feature line·작은 ball 제약을 둔다.
- local-global 반복에서 새 상태를 저장하고, `#invertedElements`가 증가하면 저장 상태로 되돌린 뒤 step size를 줄인다. 즉 “품질이 좋아졌는가”만이 아니라 **inverted 개수가 단조 감소하는지**가 rollback 기준이다.
- untangling 중 표면을 완화할 수 있지만, 그 경우 원래 표면으로 되돌리는 inversion-free deformation이 별도로 필요하다. 논문도 단순 projection은 inversion-free를 보장하지 않는다고 명시한다.
- MSJ 개선은 목표치를 0, 0.1, 0.2처럼 단계적으로 올리는 편이 안전하며, uniform-size 강제값 `ξ`를 낮추면 untangling 성공률이 올라간다. 입력 크기 정규화도 필수다.

프로젝트에 대한 판정은 보수적이다. 현재 native_hex의 표면 보존 계약 아래에서는 표면 완화 경로를 그대로 이식할 수 없다. 재사용 가능한 부분은 `bad-cell local region → fixed boundary → candidate state 저장 → inverted count 증가 시 rollback`의 **측정/거래 구조**다. 특히 현재 `HEX-ECR-4`가 네 형상에서 불일치한 사실을 이 논문이 뒤집지는 않는다. 다음 카드는 ECR 포팅이 아니라, transition component별 local region과 boundary/feature lock을 계측하는 쪽이어야 한다.

### Wei et al. 2015 — local regularization + global optimization

이 논문은 각 hex/penta를 dual-element 기반으로 이상 요소로 정규화한 뒤, 요소별 임시 이동을 모아 전역 sparse quadratic system으로 stitching한다.

- local 단계는 dual face 평균점과 outward normal로 이상 요소를 만들고, edge direction 제약과 원래 node 위치 제약을 함께 최소화해 element size를 유지한다.
- global 단계는 volumetric Laplacian, transformed-node displacement, surface geometric constraint를 합친다. surface node는 mean-value/tangent-plane 기반 normal constraint 또는 feature-point 고정으로 처리한다.
- quality 가중치는 `α_j = 1 - J(E_j)`라서 나쁜 요소의 정규화 이동을 더 크게 반영한다. 하지만 각 반복에서 전체 displacement를 풀기 때문에, **경계 lock과 feature 분류가 현재 iteration의 실제 node index와 일치해야 한다**.
- feature point는 tangent-plane Laplacian coordinate의 크기가 tolerance `σ`를 넘으면 고정하고, 그렇지 않은 표면점은 `n·Δv=0`으로 접선 이동시킨다. 논문은 feature-edge의 외부 정점을 움직이지 않도록 설계했다고 명시한다.
- 장점은 global Laplacian이 국소 정규화 요소를 stitch해 유효 mesh를 유지하려는 점이다. 한계는 octree/가변 크기 mesh에서 더 어렵고, feature-edge에 걸린 나쁜 요소는 정점 고정 때문에 개선하기 어렵다는 점이다.

프로젝트에 대한 판정은 **metric tensor→GAP-SELF→AMIPS 구간의 boundary lock 재계산**과 직접 연결된다. 다만 native_tet에는 이 논문의 hex-specific dual regularization을 넣지 않는다. 재사용할 원칙은 “현재 iteration에서 다시 계산한 boundary/feature 집합 + 전역 displacement 후 signed-volume·surface invariant 검사”이며, 이는 이미 수정한 CVT/GAP lock의 검증 근거로 기록한다.

### Zheng et al. 2025 — feature-aware singularity structure optimization

이 논문은 surface quality untangling 논문이 아니라, hex dual의 singularity structure를 sheet collapse/inflation으로 바꾸는 topology optimization 논문이다. ECR 또는 단순 sheet extraction과 혼동하면 안 된다.

- sheet operation이 column operation과 flip operation을 연속적인 sheet collapse/inflation으로 표현할 수 있음을 보이고, collapse와 inflation만으로 구조 최적화를 구성한다.
- edge의 실제 valence와 local angle로부터 ideal degree를 계산하고, `|ideal−actual|`을 energy로 사용한다. sheet collapse는 boundary edge energy가 악화되면 금지하며, paired edge와 내부 edge의 gain도 별도로 반영한다.
- inflation은 높은 degree 또는 낮은 degree singularity를 더 이상적인 degree로 나누고, boundary의 불필요한 singularity를 내부로 밀어 collapse 공간을 만든다. 초기 surface는 선택한 singular edge를 통과하도록 face를 성장시키고, 두 BFS 영역이 만나는 지점에서 pruning한다.
- feature edge의 ideal degree가 유지되도록 feature line을 따라 singularity를 보존한다. non-manifold surface가 생기면 non-manifold edge에서 성장을 멈추고 다른 face를 탐색한다.
- 저자들이 직접 보고한 한계는 우리 상황과 중요하게 겹친다. 잘못된 feature 입력, boundary/internal surface 결합으로 인한 non-manifold, feature 정렬 실패 뒤의 무한 반복이 남아 있다. 구조를 단순화하면 scaled Jacobian이 `0.7→0.15`로 악화된 사례도 있다.

프로젝트에 대한 판정은 명확하다. 현재 네 형상에서 sheet extraction이 실패했다는 사실을 뒤집는 근거가 아니라, **옥트리 transition/feature provenance가 있는 경우에만** 시도할 수 있는 별도 topology 카드의 근거다. 특히 현재 `.npz`에는 sheet의 시작 edge, feature line, patch provenance, transition-chain이 없으므로 바로 구현하지 않는다. 다음 hex 카드는 “bad component가 sheet로 표현 가능한가”가 아니라 “component의 provenance와 singular edge/face chain을 복원할 수 있는가”를 먼저 측정해야 한다.

### 세 논문을 함께 읽은 뒤의 다음 순서

1. `HEX-TRANSITION-PROVENANCE-DIAG1`: generator가 transition template, hanging-node valence, feature/patch provenance, sheet 시작·종료 edge를 출력할 수 있는지 read-only로 확인한다.
2. 가능할 때만 `HEX-TRANSITION-LOCAL-ROLLBACK1`: Xu식 local region 저장/rollback과 Wei식 현재 iteration boundary/feature lock을 결합한 **report-only candidate simulation**을 만든다. surface face-set/area가 바뀌는 후보는 승인하지 않는다.
3. Zheng식 sheet collapse/inflation은 위 두 계측에서 실제 sheet/feature correspondence가 확인된 형상에만 별도 카드로 연다. cylinder/gear처럼 ECR overlap이 0인 결과를 generic solver로 덮지 않는다.

이 순서는 논문 세 편이 공통으로 요구하는 “국소 후보, 경계/feature 제약, 적용 전후 검증, 실패 시 rollback”을 AutoTessell의 표면 보존 불변식에 맞춰 최소화한 것이다.

## 초록 또는 출판사 기록까지 확인한 hex 항목

### Elsheikh et al. 2014 — `P0 / ABSTRACT_ONLY`

[A consistent octree hanging node elimination algorithm for hexahedral mesh generation](https://doi.org/10.1016/j.advengsoft.2014.05.005)

octree refinement template가 만든 transition element를 직접 다루며, decoupling template와 circular loop로 concave region을 전처리하고 불필요한 과도 refinement를 줄이는 방향이다. 다만 현재 접근에서는 출판사 초록까지만 확인했으므로, 실제 transition quality bound와 재사용 가능한 local predicate는 아직 근거로 쓸 수 없다.

### Shepherd et al. 2006 — `P0 / FULL_READ`

[Quality Improvement and Feature Capture in Hexahedral Meshes](https://www.sci.utah.edu/publications/SCITechReports/UUSCI-2006-029.pdf)

이 공개 기술보고서는 이번 라운드에서 전문을 읽었다. 핵심은 boundary sheet를 삽입해 원래 boundary quadrilateral을 그대로 두고, 새로 생긴 내부 자유도로 기존의 나쁜 boundary-adjacent hex를 개선하는 것이다. sharp feature는 두 sheet의 교차가 만드는 edge string으로 포착한다.

- boundary sheet를 넣기 전 surface mesh를 복사하고, shrink/reconnect 뒤 원래 surface mesh를 복원한다. 따라서 “표면을 움직여 품질을 산다”가 아니라 “표면 topology를 유지하면서 내부 자유도를 만든다”는 방식이다.
- scaled Jacobian이 음수이면 convexity 손실, `0.2` 미만이면 questionable로 분류한다.
- fixed boundary와 interior-only mean-ratio smoothing을 분리한다. 논문은 boundary를 고정하면 untangled 상태를 보존하고 평균 품질을 악화시키지 않는 smoother를 사용한다고 설명한다.
- sheet가 여러 개면 feature discontinuity를 capture할 수 있지만, 이는 단순한 나쁜 면 삭제가 아니라 mesh topology와 sheet provenance를 함께 바꾸는 연산이다.

현재 `HEX-SHEET-1`의 KILL 결과를 뒤집는 근거는 아니다. 우리 4개 형상에서 “bad-face component를 sheet로 제거할 수 있는가”가 실패했기 때문이다. 다만 다음 `HEX-TRANSITION-DIAG1`에서 sheet가 **어디에서 시작·종료되고 어떤 feature/patch를 가로지르는지**를 기록해야 한다는 강한 근거가 된다. 진단 결과가 boundary sheet와 동일한 topology class를 보일 때만, 별도의 provenance-constrained sheet insertion 카드를 검토한다.

### Ito, Shih, Soni 2009 — `P1 / ABSTRACT_ONLY`

[Octree-based reasonable-quality hexahedral mesh generation using a new set of refinement templates](https://doi.org/10.1002/nme.2470)

buffer layer, refinement template, angle-based/local optimization smoothing을 사용한다. 현재 hex의 post-snap 복구에 참고는 되지만, 이 논문은 construction-time template 설계가 중심이므로 바로 post-repair 카드로 번역하지 않는다.

### Chen et al. 2025 — `P0 / ABSTRACT_ONLY`

[An adaptive hexahedral mesh generation method for industrial CT images](https://doi.org/10.1177/09544062251332170)

feature point 기반 octree partition 뒤 hanging-node transition chain을 검색 템플릿으로 제거하고, vector projection과 Laplace 최적화로 경계 mesh를 개선한다. transition chain을 “검색 가능한 국소 구조”로 다룬다는 점은 현재 patch-layer 진단의 다음 계측과 맞지만, 논문은 제한 접근이라 세부 predicate는 아직 읽지 못했다.

### Pietroni et al. 2022 — `CONTEXT / 기존 완독`

[Hex-Mesh Generation and Processing: A Survey](https://doi.org/10.1145/3554920)

pairing은 local balancing과 달리 non-local 조건이라 어렵고, transition/template·sheet·quality optimization이 서로 다른 문제라는 점을 재확인했다. 따라서 현재 “ECR 불일치” 결과를 sheet/pairing 문제로 조용히 해석하면 안 된다.

## 다음 카드의 근거와 합격 기준

### `HEX-TRANSITION-DIAG1` — 먼저 측정

기존 `PATCH-LAYER-DIAG1`의 eligible component마다 다음을 report-only로 기록한다.

1. transition-chain 길이와 hanging-node valence;
2. template class와 face warpage;
3. local scaled Jacobian/최악 skew;
4. patch/feature provenance와의 교차;
5. 같은 component에서 input boundary face-set/area가 보존되는지.

합격은 repair가 아니라 **결정론적 census**다. 세 번 반복해 같은 component ID와 같은 수치를 얻어야 하며, surface face-set/area는 0 diff여야 한다. 이 진단이 transition template와 나쁜 면을 연결하지 못하면 hex는 새 solver를 넣지 않고 문헌을 더 요청한다.

### `TET-LAZY-2` — 내부 reversible flip 측정

Dassi의 lazy flip 원칙을 이용하되 production route는 건드리지 않는다. 내부 edge만 후보로 만들고, candidate sequence 전후에 영향 cavity의 signed volume, quality, boundary face-set을 비교한다. 품질이 개선되지 않으면 sequence 전체를 rollback한다. surface vertex 이동과 병렬화는 금지한다.

### `POLY-CONCAVE-SPLIT1` — invalid cell 구조 진단

non-manifold fan의 두 invalid cell에 대해 conical decomposition 가능 여부, concave edge, patch provenance를 출력한다. `split feasible=0`이면 placement 문제가 아니라 더 깊은 primal topology 문제로 재분류한다. `split feasible=1`일 때만 transactional split 구현을 검토한다.

### `QUAD-MESSY-GRID-TOL1` — map discrepancy 원장

POSY 후보의 branch offset과 singularity별 정수 불일치를 기록한다. 허용 오차를 문헌과 fixture에서 먼저 정하고, extraction 결과를 바꾸지 않는다.

sphere는 넓은 정점 proxy까지 겹침이 0이다.

판정: **measured, falsified**. transition-only wall-fit 수정이나 repair
template를 열 근거가 없다. 다음은 transition label을 dispatch 조건으로
쓰지 않고, wall-fit 각 후보의 국소 skew/warpage/signed volume/boundary
불변식을 report-only로 측정하는 `HEX-WALLFIT-CANDIDATE-QUALITY-1`이다.

## 2026-07-26 — HEX-WALLFIT-CANDIDATE-QUALITY-1

`_wall_fit_snap`의 기존 accept/reject는 건드리지 않고, opt-in 후보 snapshot을
추가했다. 각 boundary vertex projection에 대해 영향 cell의 canonical skew,
face warpage, emitted signed volume, orientation-free volume과 전역 boundary
face-set/area를 before/trial/after로 기록한다.

작은 `max_cells=500` 진단에서 적용 후 품질 회귀는 cylinder `128/128`, sphere
`104/128`, gear `186/271`이었다. boundary face key는 모두 유지됐지만 정점이
움직이므로 area 변화는 각각 `128`, `128`, `238`건이었다. cylinder의 더 큰
`max_cells=2000`에서는 적용 회귀 `481/560`, area 변화 `521/560`이었으나
near-zero normal-distance 때문에 최대 skew outlier가 `2.7756e13`까지 튀었다.

판정: **measured, quality regression observed**. 기존 distance/envelope/
no-inversion guard는 local quality monotonicity를 보장하지 않는다. 이는
transition-only 문제가 아니라 일반 wall-fit 후보 승인 문제다. 다음 카드는
`HEX-WALLFIT-QUALITY-TRANSACTION-1`이며, skew 분모 정규화와 signed-volume
orientation 계약을 먼저 닫은 뒤 상대 품질 transaction을 검토한다.

### 계약 진단 보충

checker와 후보 진단은 모두 `max(abs(normal_dist), 1e-30)`을 사용한다. 작은
cylinder에서 최소 trial `|normal_dist|=0.0149533`, near-zero 0인데 applied
max skew Δ가 `+1.5313`이므로 작은 run의 회귀는 분모 붕괴만으로 설명되지
않는다. `2.7756e13`은 큰 run에서 나타난 별도 outlier다.

또한 실제 wall-fit no-inversion은 projection 전후 native face-sign 보존으로
판정하고, centroid fan signed-volume 합은 face winding 표현에 의존하는
report-only 값이다. 다음 transaction은 기존 face-sign 계약을 재사용하고
상대 품질 delta와 boundary area 허용오차만 추가해야 한다.
