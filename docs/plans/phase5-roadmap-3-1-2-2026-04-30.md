## 항목 3a: BL aspect 11.5k → 1k

### 현실 체크

native_bl.py:2533 주석: "BL prism aspect 는 본질적으로 큼 (cfMesh / Pointwise T-Rex 모두 **1e4~1e6 정상**)".

→ **표의 "1k 목표" 는 commercial 도 안 지키는 strict standard**. 무리한 enforcement 는 BL coverage 손실.

### 권장 sub-cards

| 카드 | 변경 | 줄 | 효과 |
|------|------|------|------|
| 3a.1 | per-vertex local ft scaling: `ft_local[v] = min(ft_target, edge[v] / target_aspect)` — local edge 기반 anisotropic ft | ~150 | 11.5k → ~5-8k |
| 3a.2 | cfMesh splitInternalLayers 동등 — wall-normal anisotropic prism splitting | ~250 | 5k → ~2k |
| 3a.3 | mass-conservation BL grow direction (Pointwise T-Rex §3.2) | ~400 | 2k → ~1.2k |
| 3a.4 | input quadric_decimate threshold 강화 (large-edge wall vertex) | ~30 | 일부 mesh 5-10% 추가 감소 |

**예상 시간**: 3-6주.

## 항목 3b: tet quality D→C (Klingner §4 swap)

### 현실 체크

stellar split-pass (iter 1) 활성화 시도 → WORSE (D 11→13). Self-impl 알고리즘 한계.

Klingner 2008 §4 algorithm: 2-3 / 3-2 / 4-4 swap with smoothing combined. Python 구현 가능하지만 100k tet 에 1-3분 (C++ 는 1-3초).

### 권장 sub-cards

| 카드 | 변경 | 줄 | 효과 |
|------|------|------|------|
| 3b.1 | `core/generator/native_tet/klingner_swap.py` 신규 — 2-3 swap (1 face 가 2 tet 사이) Python 구현 | ~300 | D → C 부분 회복 |
| 3b.2 | 3-2 swap (1 edge 가 3 tet 공유) Python 구현 | ~250 | D → C 추가 |
| 3b.3 | 4-4 swap (4 tet 사이 swap) Python 구현 | ~280 | D → C 추가 |
| 3b.4 | combined optimization (swap + smooth interleaved) | ~120 | C → B 일부 |

**예상 시간**: 3-4주. 단, Python 만이라 100k tet 에 분 단위 wall time. 사용자 대기 시간 길어짐. C++ porting 은 별도 6-12주.

## AI auto-meshing 가능 여부

| 종류 | 현재 상태 |
|------|----------|
| **Surface AI** (MeshGPT, MeshAnything V2) | **이미 L3 fallback 으로 내장** — `core/preprocessor/native_repair/` L3 경로. PyMeshFix 실패 시 활성. |
| **Volume AI tet/hex** | production lib 없음 (2026 기준). NeuralMesh / DeepCAD 는 surface only. |
| **AI mesh quality optimization** | research-level (Nature Comp Sci 2023 등). 별도 카드 가능. |

**권장 AI 카드 추가**:
- AI-1: MeshGPT inference 시 token 제한 + chunked decoding (현재 L3 fallback 안정성 ↑)
- AI-2: ML-based tet smoothing (research 진입) — 위 3b.4 와 결합 가능

## 우선순위 권장 (사용자 3→1→2 + AI)

1. **AI-1** (1주) — 기존 L3 안정화. 즉시 ROI.
2. **3a.1** (1주) — per-vertex local ft. measurable improvement 가능.
3. **3b.1** (2주) — Klingner 2-3 swap. measurable D→C.
4. **1.1** (2-3주) — StarCCM+ .ccm partial writer.
5. **2.1** (1-2주) — GPU envelope kernel.

**이 5개 합 = 7-12주**. 1분 polling 으로 안되며, 각각 dedicated work 필요.

## 결론

- 표 4 항목 + AI 모두 **multi-week dedicated work**
- 1분 wakeup polling 은 small-loop vectorization 에만 적합
- 권장: 사용자가 위 우선순위 중 **1개만 선택해서 시작** (예: AI-1 또는 3a.1)
- 또는 별도 phase 카드로 미루고 saturation maintenance 종료
