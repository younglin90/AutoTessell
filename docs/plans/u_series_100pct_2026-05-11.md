cases at ``target=10000``:

refinement loop dominates the edge_length_r hint.  Closing this gap
requires either a 2-shot feedback loop (2× runtime) or replacing
pytetwild — multi-week scope.

Draft is the bench default and matches the CLI default in ``cli/main.py``.
The standard/fine failures stem entirely from **input STL quality**:
extreme_1017017, hard_100030, hard_1004826 each have 55+ self-intersections

produces an output surface whose Hausdorff distance to the original
exceeds 5 % bbox diagonal — a real geometric divergence, not a pipeline
defect.  Fixing requires either Boolean-union-style multi-shell repair
in the preprocessor or a sliver-aware tet generator — multi-week scope.
