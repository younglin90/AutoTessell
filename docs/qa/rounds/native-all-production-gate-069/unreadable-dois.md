# Unreadable DOI ledger — round 069

These DOI records remain unresolved in this round. They are not cited as
read evidence; each question is the design question needed before using the
paper to change a release gate.

- `10.1145/355483.355487` — need the exact critical-weight/sliver criterion,
  its monotonicity assumptions, and whether it can be used as a bounded
  post-quality optimization objective without weakening topology/source
  authority.
- `10.1002/(SICI)1097-0207(20000720)48:8<1165::AID-NME940>3.0.CO;2-Y` — need
  the precise Knupp metric definitions, normalization, and recommended
  thresholds for comparing Tet/Hex/Prism-like cells without mixing metrics.
- `10.1002/nme.7644` — need the boundary-layer front construction,
  collision/concavity handling, and which quality quantities are guaranteed
  versus merely optimized.
- `10.1016/j.compfluid.2026.107032` — need reproducibility and
  quality/cell-count trade-off evidence on non-cubic and wall-layer cases.
- `10.1002/nme.341` — only an abstract-level reference was available; need
  the full algorithm, admissibility conditions, and evidence relevant to
  source-boundary/feature preservation.

Until these are read, implementation relies on the accessible primary
sources in `literature.md` and no DOI-only result may be presented as a
literature-backed release threshold.
