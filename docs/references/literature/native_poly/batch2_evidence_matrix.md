# Native Poly Literature Review - Batch 2 Evidence Matrix

Scope: nine papers. The first six are the original set; three additional
high-value papers were added from user-supplied PDFs in this pass. Every paper
marked `FULL_READ` was read page by page from an accessible PDF and at least one
representative page was rendered and visually inspected.

## Cross-paper decision

The evidence does not support one monolithic `native_poly` algorithm. It supports
four explicit layers:

1. **Site and constraint layer.** Use Poisson spacing or optimized sites, but
   preserve boundary, interface, patch, and mixed-dimensional provenance.
2. **Robust cell-construction layer.** Use Delaunay/Voronoi adjacency propagation
   and a topology-preserving half-space clipper. Nearest-point snapping is not a
   substitute for this layer.
3. **Transactional topology layer.** Agglomeration, collapse, dissolve, and split
   operations must validate a local incidence neighborhood and roll back on
   failure.
4. **Staged quality layer.** Reject invalid topology or empty star kernels before
   ranking warpage, scale, non-orthogonality, skewness, or solver-specific error
   proxies.

## Priority implementation hypotheses

| Priority | Hypothesis | Minimum falsification test |
|---|---|---|
| P0 | A shared oriented face-loop/half-edge representation can eliminate inconsistent clipped-cell face reconstruction. | Randomly clip convex cells through coplanar, vertex-on-plane, and edge-on-plane cases; every result must satisfy closed incidence, Euler consistency, positive volume, and deterministic face cycles. |
| P0 | Replacing unconditional polyhedral cell deletion with transactional local edits prevents boundary holes. | For every attempted repair, compare boundary patch area, connected components, and interface face pairing before and after commit. |
| P1 | Incident-pair propagation is faster and more complete than per-cell global nearest searches for clipped Voronoi construction. | Compare processed pairs, wall time, missing boundary cells, and peak memory on increasing site counts with the same background tet mesh. |
| P1 | A quality vector catches failure modes hidden by current non-orthogonality/skewness summaries. | Add topology, signed volume, star-kernel, face warpage, min edge/face/cell scale, and current CFD metrics; inject one defect of each class and require unique detection. |
| P2 | Poisson separation plus maximal coverage produces more predictable interior polyhedral cells than jittered Cartesian seeds. | Compare inradius/outradius, short-edge tail, face count, non-orthogonality, and runtime on identical domains and budgets. |
| P2 | Patch/interface provenance can serve as a hard barrier in agglomeration. | Agglomerate a multi-region mesh and require unchanged patch IDs, material adjacency, interface pairing, and manifoldness. |
