# CARD BETA2280_VVV9K3_IMPROVEMENT_ATTEMPT (beta2280) — fTetWild §3.3 worst-cell improvement attempt helper (sim-only)

**target_engine**: tet
**모티프**: fTetWild §3.3 Alg 2 (worst-first improvement pass) + Klingner 2008 §3 4-op selection (collapse / 3-2 swap / 4-4 swap / smooth)

## 이론적 근거 (≤30줄)

- **문제 정의**:
  VVV9K1 (init) + VVV9K2 (pop) 으로 worst-first heap 인프라 완성.
  다음 단계: pop 한 cell c 에 대해 4-op 후보 중 **가장 큰 ΔE 개선** 을 가져오는 op 1개를
  시뮬레이션으로 결정 (apply 안 함). 결과는 (success, op_type, ΔE, sim_pts, sim_tets).
- **AMIPS energy** (Hu fTetWild eq.1):
  E(σ) = Σ tr(JᵀJ)^(α/2) / det(J)^(2α/3),  α = 1.0
  ΔE = E_post - E_pre  (음수 = 개선).
- **op selection** (Klingner Table 1):
  - `vertex_smooth`: 1-ring AMIPS Laplacian 1 step (VVV9J4 reuse 후보).
  - `edge_collapse`: shortest edge of c 가 ε-envelope 위반 없을 때 collapse.
  - `flip_3_2` / `flip_4_4`: 기존 helper (VVV3b / VVV5b) per-cell 1-shot.
  - 가장 ΔE_min < 0 작은 op 1개 선택.
- **단조성**: post.min_q ≥ pre.min_q (star-local) AND post_n_neg = pre_n_neg.
  미달 시 success=False, sim arrays 미반환 (None).
- **레퍼런스**: fTetWild §3.3 Alg 2 line 5-10, Klingner 2008 §3 Table 1.
- **혁신성**: novelty 1 / rigor 2 / impact 1 = 4 (스켈레톤 단계, 본격 활성은 VVV9K4+).
