# CARD BETA2265_VVV9I1_ENVELOPE_PROJECT_HELPER (beta2265) — fTetWild §3 envelope point projection helper

**target_engine**: tet
**모티프**: fTetWild (Hu 2020) §3.2 envelope projection — point snap onto thin shell tube preserving topology

## 이론적 근거

- **문제 정의**: native_tet self-only (P4-C OFF) 의 worst_mq 격차. fTetWild baseline worst≈0.20 은 envelope projection (thin shell ε-tube around input surface) 으로 표면 점이 envelope 밖으로 escape 시 강제 snap. 현 native_tet 은 envelope 검사만 (`envelope.py` 127 line) — projection snap 없음.
- **핵심 아이디어**: 각 vertex `p` 에 대해 envelope 표면점 `q*=argmin‖p-q‖` 계산. `‖p-q*‖>eps` 시 후보 snap 위치 `q*` (정확 snap). 단조성: pre dihedral 보존 (`min(dihedral_around(p))` 비감소만 허용 — caller 활성 시).
- **레퍼런스**: Hu 2020 fTetWild §3.2 (envelope ε-shell) + §3.5 smoothing projection step. 자체 코드 `envelope.py:_inside_envelope`.
- **혁신성**: novelty=1 (기존 기법 helper 추출), rigor=2 (dihedral 단조 가드 명시), impact=2 (self-only worst_mq margin). 합=5 — pass.

## 변경

- 파일: `core/generator/native_tet/stellar.py` (single-file 원칙, 1594→≤1674 line)
- 함수: `_envelope_point_projection(pts, envelope_pts, eps, lock_ids=None)` 신규
- 핵심 변경 (≤80줄):
  1. scipy.spatial.cKDTree 로 envelope nearest point query (지연 import).
  2. 각 vertex 거리 `d_i` 계산, `d_i>eps` 인 vertex 만 후보.
  3. snap target = nearest envelope point (정확 snap, outward offset 미적용).
  4. dry-run dict reservation: `{"n_violated":..., "n_snapped":0, "max_d":..., "applied":False}`.
  5. **default OFF — no caller**, helper 만 정의. lock_ids 인자로 BL/feature vertex skip.
- 단조 가드 (caller 활성 시, 본 카드 미적용): per-vertex pre/post dihedral_min 비감소 시만 commit, 위반 시 revert.
- AVOID 준수: envelope-bounded relocation default-ON 금지 (SSS2/SSS3 reject), Steiner cavity insert 금지, smooth_amips BSP 직후 호출 금지, collapse_short_edges flip 후 금지.
