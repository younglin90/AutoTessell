- **신 라인 문제 정의**: tet worst_mq=0.2069 plateau 는 hard-mesh 의 **short cap edges** 가 sliver 만들어 worst quality 를 압박. fTetWild §3.3 4-op 중 *contraction* 이 cap edge 제거에 가장 효과적 (Klingner 2008 Table 1: contraction alone +18% worst_q on Stanford bunny).
- **본 카드 (sequence #1, skeleton-only, pure)**:
  1. 함수 `_klingner_edge_contract_candidates(pts, tets, *, q_max, l_max_factor, max_candidates) → list[tuple[int,int,float]]`.
  2. Edge enumeration via 기존 `compute_edge_incident_tets_cached(tets)` (line 24, cached).
  3. Filter: edge 길이 < `l_max_factor * median_edge_length` 만 후보; incident tet 중 quality < `q_max` 1개 이상.
  4. Weak-link pre-check (vertex-share count) — full link condition (Edelsbrunner-Shah 1997) 다음 카드.
  5. Simulate contract `b → a`: `np.where(t==b, a, t)` reindex, drop tets containing both endpoints, recompute `_tet_quality` for affected tets only.
  6. Append `(min(a,b), max(a,b), post_min_q)` only if `post_min_q >= pre_min_q - 0.005` (monotone guard).
  7. Sort by post_min_q desc, cap at `max_candidates`. Return list.

- **레퍼런스**: Klingner & Shewchuk 2008 §4.1 (pp.6-7 contraction algorithm + Fig.5 link condition); Edelsbrunner & Shah 1997 (link condition); fTetWild §3.3 (Hu 2020).
