### Cheng-Dey-Edelsbrunner 핵심 (paper §3.2-§4.1)
- 각 vertex v 에 weight w(v) ≥ 0 부여, weighted distance π(p,v) = ‖p-v‖² - w(v).
- Weighted Delaunay 의 sliver 회피: For sliver tet σ with vertices {v_i}, exists weight assignment {w(v_i) ∈ [0, ω₀²·ρ²]} such that σ는 weighted Delaunay 에 등장 안 함 (Theorem 3.4 quality ≥ τ for τ=σ_0/2^α).
- 실용 근사 (paper §4): 각 정점 w(v)=ε(v)², ε(v) = α · l_min(v) · γ ; γ ∈ [0, 1] 균일 무작위 후보 K 개 평가 → max-min q 선택. Topology 재구성 X — pure 정점 가중치 perturbation 만 시뮬레이션.
