# CARD BETA2273_VVV9J4_NEWTON_COMPOSE (R208) — Full SLIM Newton step compose helper

**target_engine**: tet
**모티프**: SLIM Algorithm 1 (Rabinovich 2017 §3) — chained jac → grad → line-search → step apply (simulation only, mesh unchanged)

## 이론적 근거 (≤30줄)

- **문제 정의** (수식): 단일 정점 v 에 대한 한 번의 SLIM Newton step:
    F_t(V) → ∇E_SD(F_t) → d_v = -Σ_{t∈star(v)} (∂E/∂F_t · ∂F_t/∂x_v) → α* by Armijo →
    V_new[v] = V[v] + α* · d_v, with E_post ≤ c1 · E_pre and det F_t > 0 ∀t∈star(v).
  R204-R207 으로 4개 sub-helper (jac / SD / grad / line-search) 가 모두 helper-only 로 존재. 단 한 번도 chained 호출이 검증되지 않아 end-to-end skeleton 미완성.
- **본 카드의 핵심 아이디어** (compose 단계, mesh 0 변경):
  1. star(v) 추출 → `_slim_local_jacobian_per_tet(V_pre, star)` 로 F, det_F, frob_F2, cof_F.
  2. `_slim_symmetric_dirichlet_energy(jac)` 로 E_pre = Σ.
  3. `_slim_compute_local_gradient(jac)` 로 ∂E/∂F (T,3,3); per-tet 합 reduce → direction d_v ∈ ℝ^3 (descent: d_v = -Σ trace projection, 1차 근사). norm < 1e-14 → reject.
  4. `_slim_armijo_line_search(pts, tets, v_idx, d_v, max_step)` → α*, accepted, n_iter_used, E_post.
  5. accepted=True → new_pos = pts[v_idx] + α*·d_v ; energy_delta = E_pre - E_post.
- **레퍼런스**: Rabinovich 2017 SLIM §3 Algorithm 1; 사내 helpers (stellar.py:1777, 1868, 1927, 1972).
- **혁신성 평가**: novelty 1 + rigor 2 (Armijo monotone carry-over) + impact 2 (end-to-end skeleton 완성, R209+ caller 발판) = **5/9**, 통과.

## 변경

- 파일: `core/generator/native_tet/stellar.py` (단일 파일)
- 함수: `_slim_newton_step_one_vertex(pts, tets, v_idx, max_step=0.1)` 신규, 기존 line-search 직후 (line ~2052) 부착.
- 핵심 변경 (≤80줄):
  1. 게이트 `_VVV9J4_NEWTON_COMPOSE: bool = False` (default OFF).
  2. star mask 추출, 빈 star → reject dict.
  3. V_pre = pts.copy(); jac_pre = `_slim_local_jacobian_per_tet`; E_pre = Σ `_slim_symmetric_dirichlet_energy`.
  4. grad_per_tet = `_slim_compute_local_gradient(jac_pre)`; d_v = -np.sum(grad_per_tet[:, :, 0], axis=0) (descent reduce, 1-axis projection); norm guard.
  5. ls = `_slim_armijo_line_search(pts, tets, v_idx, d_v, max_step)`; accepted/E_post 추출.
  6. accepted → new_pos = pts[v_idx] + ls["alpha"] * d_v; energy_delta = E_pre - ls["E_post"].
  7. 반환 dict(new_pos: (3,), energy_delta: float, n_iter_used: int, accepted: bool).
- 단조 가드: pts/tets 절대 mutate 금지 (V_pre/V_try copies). caller 없음 → mesh state 0 변경.
