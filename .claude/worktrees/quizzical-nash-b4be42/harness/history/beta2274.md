# CARD BETA2274_VVV9J5_GLOBAL_PASS (beta2274) — SLIM global pass helper (sweep + simulate)

**target_engine**: tet
**모티프**: Rabinovich 2017 "SLIM" §3 Algorithm 1 outer loop (per-iter sweep over all interior vertices); Klingner 2008 §3 vertex-smoothing pass

## 이론적 근거 (≤30줄)

- **문제 정의** (수식): 각 interior vertex `v` 에 대해 SLIM Newton step 으로 SD energy 감소.
  Total descent: `ΔE_total = Σ_v (E_pre(v) - E_post(v))`. Mesh 무변경 조건 — `pts_new[v]` array 만 누적.
- **본 카드의 핵심 아이디어**:
  1. 단순 sweep helper `_slim_global_pass(pts, tets, *, max_iters, eps)` — interior vertex 순차 호출 `_slim_newton_step_one_vertex` (R208 카드 helper).
  2. boundary lock — `tets` 의 face 중 1회 등장 face 의 vertex 집합 → 제외 (interior-only).
  3. iter loop — `max_iters` 회 (default 5), `ΔE_iter < eps` 조기 종료.
  4. **mesh topology 무변경**: tets 인덱스 수정 X, `pts.copy()` 만 변형해 반환 (caller 가 적용 결정).
  5. inverted detection — R208 helper 의 reject 케이스를 `n_inverted_avoided` 로 카운트.
- **레퍼런스**: Rabinovich et al. 2017 "Scalable Locally Injective Mappings" §3 Algorithm 1 (outer pass); R208 카드 (`_slim_newton_step_one_vertex`).
- **혁신성 평가**:
  - novelty 1 (R204-R208 helper 시퀀스 마무리, sweep wrapper).
  - rigor 2 (per-vertex Newton already monotone; sweep 합산도 단조 ≥ 0).
  - impact 1 (이 카드 자체 metric 변화 없음 — mesh 무변경; 후속 카드에서 caller 활성 시 SD energy 감소 기대).
  - 합 = 4 (skeleton-only 단계, sequence finalizer).
