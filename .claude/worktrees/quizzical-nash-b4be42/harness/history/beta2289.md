# CARD BETA2289_VVV9P1_MULTI_FACE_REMOVAL_HELPER (beta2289) — Klingner Stellar §3.4 multi-face removal candidate enumerator

**target_engine**: tet
**모티프**: Klingner & Shewchuk 2008 "Aggressive Tetrahedral Mesh Improvement" §3.4 — Multi-Face Removal (3-2 / 4-4 flip 의 일반화).  새 알고리즘 라인 P 의 첫 카드 (skeleton).

## 이론적 근거 (≤30줄)

- **문제 정의**: 단일 face 의 2→3 / 3→2 flip 만으로는 worst_mq 0.208 → 0.20+ 격차 (vs fTetWild 0.20–0.30 industrial reach) 를 추가로 좁히기 어려움. 인접한 다중 face 가 동시에 낮은 quality star 를 형성할 때, 단일 flip 은 local minimum 에 빠진다.
- **핵심 아이디어** (Klingner 2008 §3.4 eq. 2): worst tet 의 4개 face 각각에 대해 incident-tet star S_f = {t | f ∈ t} 의 min-quality q*(f) = min_{t ∈ S_f} Q(t) 를 계산하고, q*(f) < q_thr 인 face 만을 **multi-face removal** 후보로 enumerate. 이는 3-2 (|S_f|=2) / 4-4 (|S_f|=4) flip 의 통합 candidate generator 로, line K (priority queue) 의 보조 워크리스트가 된다.
- **본 카드의 변경**:
  1. 신규 `_multi_face_removal_candidates(pts, tets, *, k_worst=64)` helper — sorted-face-key 캐시 (`compute_face_incident_tets_cached`) 재사용, worst-q tet 의 face star 만 enumerate.
  2. 반환: `list[dict]` = [{"face": (a,b,c), "star_size": int, "min_q": float, "owner_tet": int}], k_worst limit 로 wall-time bounded.
  3. **default OFF**: caller 추가 안 함, mesh 변경 없음 (R197/R208/R220 skeleton 정책 준수).
- **레퍼런스**: Klingner & Shewchuk 2008 §3.4 + Table 1 (3-2 / 4-4 ring removal); 기존 `compute_face_incident_tets_cached` (line 74) 재사용.
- **혁신성**: novelty 2 (기존 line H/J/K 외 새 line P 시작) + rigor 2 (read-only enumeration, monotone safety inherited) + impact 2 (multi-face removal 은 fTetWild 가 명시적으로 구현하지 않은 영역). 합 = 6 ≥ 5.

## 변경

- 파일: `core/generator/native_tet/stellar.py` (단일 파일, 기존 2699 줄 끝에 ≤80줄 append)
- 함수: `_multi_face_removal_candidates(pts, tets, *, k_worst=64) -> list[dict]`
- 핵심 변경 (≤80줄):
  1. `_tet_quality` vectorize → top-K worst tet 추출 (`np.argsort(q_arr)[:k_worst]`).
  2. `compute_face_incident_tets_cached(tets)` 재호출 (LRU 캐시 hit O(1)).
  3. worst tet 의 4 face 각각에 대해 incident star size 와 star min_q 계산, `min_q < q_thr` 만 후보 list 에 push.
  4. tie-break: star_size desc, min_q asc.
  5. caller 추가 안 함 (default OFF). VVV9P2+ 카드에서 diag hook → apply 활성화 예정.
- 단조 가드: 호출되지 않으므로 mesh 변경 0. helper 내부에서도 read-only (deepcopy 불필요, np.argsort 만 사용).
- AVOID 준수: collapse/relocation/Steiner cavity 미사용. flip_edges_54 호출 없음. enumeration only — VVV5 / VVV4 / SSS3 패턴 회피.
