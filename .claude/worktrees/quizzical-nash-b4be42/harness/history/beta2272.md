# CARD BETA2272_VVV9J3B_LINE_SEARCH (beta2272) — SLIM Armijo line-search helper (skeleton)

**target_engine**: tet
**모티프**: Rabinovich et al. 2017 "Scalable Locally Injective Mappings" §3 eq.(5)–(6) (SLIM Newton step) + Smith & Schaefer 2015 "Bijective Parameterization with Free Boundaries" §4 (proxy line search). Sub-card #3b of VVV9J Newton-step sequence (after #1 Jacobian, #2 SD energy, #3a gradient).

## 이론적 근거 (≤30줄)

- **문제 정의 (수식)**: SLIM Newton step은 vertex 위치 v_idx에 대해
  ``v ← v + α · d`` (d=−H⁻¹∇E, R206 helper).
  여기서 α∈(0,1] 가 잘못 선택되면
  (a) ∃ tet t ∈ star(v_idx) 에서 ``det F_t ≤ 0`` (inverted),
  (b) ``E_SD^post > E_SD^pre`` (energy 증가).
  표준 backtracking Armijo 조건:
  ``E(v + α d) ≤ E(v) + c1·α·∇E(v)·d``,  α ← α/2  반복.
- **본 카드 핵심 아이디어** (helper-only, mesh 무변경):
  1. star(v_idx)= ``{t : v_idx ∈ tets[t]}`` 을 단일 패스로 추출 (O(T) 마스크).
  2. step ladder ``α_k = max_step · 0.5^k`` (k=0..n_iter−1, 기본 max_step=0.1).
  3. 각 α_k 에서 시뮬레이션 좌표 ``v' = pts[v_idx] + α_k · direction`` → 기존 ``_slim_local_jacobian_per_tet(V_sim, star_tets)`` + ``_slim_symmetric_dirichlet_energy`` 재호출 → ``E_post``.
  4. 수락 조건 (둘 다 만족):
     - ``min_t det F_t > eps_det`` (eps_det=1e-14 — VVV9J1과 동일 임계),
     - ``E_post ≤ c1 · E_pre + 1e-12`` (c1=0.5 default, Armijo 변형: 단조 감소 + 50% margin → degeneration 방지 우선).
  5. 첫 수락 α 반환; 모두 실패 시 ``alpha=0.0`` 반환 (caller가 step 거부).
- **단조성/안정성**: c1≤1 이므로 수락된 α 는 반드시 E 감소; α=0 fallback 보장. caller 0건 (helper-only) → 회귀 0 보장.
- **레퍼런스**: Rabinovich 2017 §3 eq.(5–6); Smith & Schaefer 2015 §4; Nocedal & Wright "Numerical Optimization" 2006 §3.1 Armijo backtracking.
- **혁신성 평가**: novelty 1 (기존 SLIM line-search 자체 구현 신규 적용) · rigor 2 (Armijo 단조 감소 + det>0 동시 가드) · impact 2 (VVV9J Newton 시퀀스의 핵심 안전 가드 — apply 카드 진입 사전 조건). 합 5 → 통과.

## 변경

- 파일: ``core/generator/native_tet/stellar.py`` (단일)
- 함수: ``_slim_armijo_line_search`` (≈1962 line 직후 신규 helper)
- 핵심 변경 (≤80줄):
  1. 모듈 게이트 ``_VVV9J3B_LINE_SEARCH: bool = False`` 추가 (default OFF, no caller).
  2. ``_slim_armijo_line_search(pts: np.ndarray, tets: np.ndarray, v_idx: int, direction: np.ndarray, max_step: float = 0.1, c1: float = 0.5, n_iter: int = 10) -> dict`` 신규.
     - star mask: ``np.any(tets == v_idx, axis=1)`` → ``star = tets[mask]``.
     - star 비어있거나 ``np.linalg.norm(direction) < 1e-14`` → ``{"alpha": 0.0, "n_iter_used": 0, "E_pre": np.inf, "E_post": np.inf, "accepted": False, "n_inverted": -1}``.
     - V_pre 복사본 (``pts.copy()``)에서 ``E_pre = float(np.sum(_slim_symmetric_dirichlet_energy(_slim_local_jacobian_per_tet(V_pre, star))))``.
     - α ladder loop ``for k in range(n_iter): alpha = max_step * (0.5**k)`` → ``V_try = pts.copy()``, ``V_try[v_idx] = pts[v_idx] + alpha * direction``.
     - star 한정 jac/energy 재계산. ``det_F = jac["det_F"]``; ``n_inv = int(np.sum(det_F <= 1e-14))``.
     - ``n_inv == 0 and E_post <= c1 * E_pre + 1e-12`` → 수락 dict 반환 (alpha, n_iter_used=k+1, E_pre, E_post, accepted=True, n_inverted=0).
     - 모두 실패 → ``alpha=0.0, accepted=False`` dict 반환.
- **단조 가드**: helper-only (caller 없음) → mesh 무변경 보장. ``pts`` 인자는 mutate 금지 (``V_try = pts.copy()`` 강제).
