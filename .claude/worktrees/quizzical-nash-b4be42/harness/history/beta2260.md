  1. `pts_out, tets_out = pts.copy(), tets.copy()`; `n_applied=0, n_reverted=0, n_conflict=0`.

  4. return `(pts_out, tets_out, {"n_applied": n_applied, "n_reverted": n_reverted, "n_conflict": n_conflict})`.
