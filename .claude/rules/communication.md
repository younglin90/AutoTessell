## Communication

- **Reply to the user in Korean** — it is their working language.
- **Concise engineering tone; lead with the conclusion**, then supporting detail.
- **Reference files as clickable `path:line`** (e.g. `core/generator/pipeline.py:142`)
  so the user can jump straight to the code.
- **Project docs and CLAUDE.md are written in English** per Anthropic guidance, even
  though chat replies are in Korean. Keep that split: code/docs in English, conversation
  in Korean.
