## 이론적 근거 (VVV9J SLIM chain #2)

- **문제 정의**: R204 (VVV9J1) 가 per-tet Jacobian F, ||F||_F² (frob_F2), det F 를 채웠다. SLIM 의 핵심 에너지인 Symmetric Dirichlet (SD) 은 fold-over 시 무한대로 발산해 inversion 자동 방지.
  E_SD(F) = 1/2 ( ||F||_F² + ||F^-1||_F² )
- **핵심 아이디어** (수식):
  1. ||F^-1||_F² = ||cof(F)||_F² / det(F)² (F^-1 = cof(F)^T / det F).
  2. cof(F) (T,3,3) batched: NumPy 전용 — adjugate 닫힌식 (3×3 minor expansion).
  3. E_SD = 0.5 · (frob_F2 + frob_cof2 / det_F²).
  4. inverted (det F ≤ 0) 또는 degenerate (|det F| < 1e-14) → +inf.
- **레퍼런스**: Rabinovich 2017 §3 eq.(3); Smith & Schaefer 2015 "Bijective Parameterization"; 기존 helper `_slim_local_jacobian_per_tet @ stellar.py:1777`.
- **혁신성 평가**: novelty 1 (SLIM 표준 에너지 자체 포팅) + rigor 3 (단조 +inf 보장) + impact 2 (sliver/inverted 진단 + 향후 SLIM 최적화 fuel) = **6**.

## 변경

- 파일: `core/generator/native_tet/stellar.py` (단일 파일)
- 함수 신규: `_slim_symmetric_dirichlet_energy(jacobians) -> np.ndarray` (line ≈ 1858, 기존 helper 직후)
- 입력: VVV9J1 의 dict (`F`, `det_F`, `frob_F2`).
- 핵심 변경 (≤ 60줄):
  1. flag `_VVV9J_SD: bool = False` (default OFF, no caller).
  2. cof(F) 닫힌식 (3×3 adjugate) — NumPy fancy-index, einsum 없는 stable form.
  3. `frob_cof2 = einsum("tij,tij->t", cof_F, cof_F)`.
  4. mask = (det_F > 1e-14) & (det_F > 0). inv_term = frob_cof2 / det_F²  on mask, else +inf.
  5. E_SD = 0.5 · (frob_F2 + inv_term), 마스크 false 위치 +inf.
  6. return ndarray (T,) float64.
- 단조 가드: caller 없음 → 회귀 0 (구조적). 호출 hookup 은 다음 카드 (VVV9J3).
